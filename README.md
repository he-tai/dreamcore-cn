# 中式梦核 · 概念站（v5）

纯氛围概念站。无简历、无公司、无个人介绍。  
晚自习后的绿墙、瓷砖楼道、网吧 CRT、单元楼道对讲灯、候车室蓝椅——熟悉却说不清是第几次。

**隐线：** 今晚本该走。网吧未注销的号、楼道无人接的对讲、候车室还凹着的位子——三处残迹拼同一件未完成的离开。

## 运行

```bash
python3 -m http.server 8765
```

打开 `http://localhost:8765`。

## 五幕 + 记忆图

1. **入梦** — 黑板 + 粉笔粉尘层 · 荧光闪 · 博物馆题记逐字  
2. **走廊** — 粘性卷轴 · 四层摄影板视差 · 卷轴字幕 · 安静门廊  
3. **入室** — 微章节：入场低语 → 碎片探查 → 一次抉择 →「后果」拍 →「…回走廊」  
4. **记忆图** — 褪色平面图非线性跳转 · 去过/抉择软标记  
5. **残响** — 便利贴随路径增减 ·「拼出来的句子」逐步写全  
6. **醒来** — 漂白光泄漏 · 2–4 行分支终章 ·「再入一次」清空账本

## 记忆账本（本次入梦）

- `sessionStorage` 记录碎片、抉择、访问顺序；顶栏「记忆 n/10」  
- 每房探索约两处后出现抉择；抉择后有短暂「后果」与回走廊暗示  
- 跨房链条：登机器 → 楼道「卡号」→ 往上走 → 候车室「硬币」→ 双抉择后「未写完的字」  
- 入场低语会承认先前去过的房间（顺序可换，文案不同）  
- 残响拼句：今晚…… → 今晚本该走。 → 今晚本该走。你没走。  
- 卡住时极淡中文提示（如「点开有光的地方」），非教程面板

## 试玩路径（建议）

### 路径 A · 未互动 / 未完成的离开
1. 只向下滚动，不进门  
2. **醒来**应接近：`天亮了。 / 你什么也没带上。 / 像从没打算走。`

### 路径 B · 闭环（接上链条）
1. 网吧：点两处有光碎片 → **登那台还亮着的机器** → 读后果  
2. 楼道：找新解锁的「网吧卡」碎片 → **不下楼，往上走**  
3. 候车室：取「还温的硬币」与「未写完的字」→ 任选坐下或擦雾  
4. 残响：应出现卡号/硬币/等我—— 便利贴，拼句写全  
5. **醒来**应接近闭环：`卡号、硬币、未写完的字。 / 这一次，链条接上了。 / … / 你好像还会再来。`

### 路径 C · 有意留下
1. 网吧选 **把风扇关掉**  
2. 楼道选 **不下楼，往上走**  
3. 候车室选 **擦掉玻璃上的雾**  
4. **醒来**应接近：`你没有走。 / 风扇关了。对讲静了。雾开了。 / 梦把你送回同一扇门。`

### 路径 D · 浅尝
1. 只进一间、点一两处、不做抉择（或极少）  
2. **醒来**偏：`几乎忘了。` 或未拼完的中段题记

「再入一次」清空账本后可重走。

## 技术

- 自托管 Noto Serif/Sans SC（站点字形子集 ~240KB）  
- 本地 Lenis + GSAP ScrollTrigger  
- WebP 成片 + 特写板；无新重型库、无新 AI 图  
- 程序化声场；默认静音 + 微型 EQ  
- `prefers-reduced-motion` / 触屏 / 窄屏  
- **无** Three.js 盒廊 · **无** 英文 UI chrome（除可选 credit）

## 诚实差距

- 成片仍为生成图，非实拍扫描序列  
- 声场为合成，非空间 Foley  
- 房间为 2D 层 + 特写 rack，非连续三维漫游
