# 中式梦核 · 概念站（v5）

纯氛围概念站。无简历、无公司、无个人介绍。  
晚自习后的绿墙、瓷砖楼道、网吧 CRT、单元楼道对讲灯、候车室蓝椅——熟悉却说不清是第几次。

## 运行

```bash
cd /workspace/dreamcore-cn
python3 -m http.server 8765
```

打开 `http://localhost:8765`。

## 记忆账本（本次入梦）

- `sessionStorage` 记录碎片与抉择；顶栏「记忆 n/8」极淡提示  
- 每房探索约两处后出现抉择（网吧 / 楼道 / 候车室）  
- 跨房：网吧「登机器」解锁楼道卡号碎片；楼道「往上走」解锁候车室硬币  
- 离开房间后走廊偶发一句回声；门廊可显「去过」  
- 醒来随路径分支：天亮了 / 记得更多 / 几乎忘了 / 有人在等 / 灯还没关

## 技术

- 自托管 Noto Serif/Sans SC（站点字形子集 ~240KB）  
- 本地 Lenis + GSAP ScrollTrigger  
- WebP 成片 + 新特写板（门把手 / 对讲 / CRT / 瓷砖 / 粉尘 / 记忆图）  
- 程序化声场：底噪 · 60Hz 灯管 · 低频 drone · 对讲双响 · 开机咔嗒 · 默认静音 + 微型 EQ  
- `prefers-reduced-motion` / 触屏 / 窄屏  
- **无** Three.js 盒廊 · **无** 英文 UI chrome（除可选 credit）

## 诚实差距

- 成片仍为生成图，非实拍扫描序列  
- 声场为合成，非空间 Foley  
- 房间为 2D 层 + 特写 rack，非连续三维漫游
